# Geely E2 EV (Geely EX2) - บันทึกค่าชาร์จและคำนวณอัตราสิ้นเปลือง ⚡

เว็บแอพพลิเคชันบันทึกและคำนวณอัตราสิ้นเปลืองค่าชาร์จรถไฟฟ้า สำหรับ **Geely E2 EV (Geely EX2 / Xingyuan)** ออกแบบให้ใช้งานง่าย สะดวกรวดเร็ว ทั้งบนคอมพิวเตอร์และมือถือ

---

## ⚡ คุณสมบัติเด่น:
1. **ออกแบบเพื่อความสะดวกและรวดเร็ว:**
   - รวมสถานีชาร์จสาธารณะยอดนิยมในไทย (PEA Volta, PTT EV Station PluZ, EA Anywhere, EleXA, Evolt, Shell Recharge ฯลฯ) พร้อมปุ่มคีย์ลัดกดทีเดียวได้ทันที
   - ปุ่มลัดเพิ่มจำนวนเงิน (+100, +200, +300, +500, +800) กรอกเสร็จใน 5 วินาที
2. **ช่องเลขไมล์ (Odometer):**
   - มีช่องเลขไมล์แสดงอยู่บนฟอร์มหลัก **(ไม่บังคับใส่ — ปล่อยว่างได้ 100%)**
3. **ระบบคำนวณอัตราสิ้นเปลืองอัตโนมัติ (บาท/กม.):**
   - **คำนวณได้ทันที!** เมื่อใส่จำนวนเงินที่ชาร์จ + เลขไมล์อย่างน้อย 2 ครั้ง
   - สูตรคำนวณ: `อัตราสิ้นเปลือง (บาท/กม.) = จำนวนเงินที่ชาร์จ ÷ (เลขไมล์ปัจจุบัน - เลขไมล์ครั้งก่อนหน้า)`
   - แสดงผลใน **การ์ดสรุปภาพรวมด้านบน** และ **แต่ละรายการในประวัติการชาร์จ** (เช่น `0.73 บาท/กม. (วิ่งไป 300 กม.)`)
   - มีระบบคำนวณเปรียบเทียบว่า **ประหยัดกว่ารถน้ำมันไปกี่บาทต่อกิโลเมตร** และสรุปยอดเงินที่ประหยัดได้รวม
4. **กราฟสรุปและรายงาน:**
   - กราฟสรุปค่าใช้จ่ายแยกตามรายเดือนและตามสถานีชาร์จ
   - ค้นหาและกรองประวัติตามสถานีหรือเดือนที่ชาร์จได้
5. **ระบบสำรองและส่งออกข้อมูล (Backup & Export):**
   - ส่งออกข้อมูลเป็นไฟล์ Excel / CSV ได้ทันที
   - สำรองข้อมูลและนำเข้าข้อมูล JSON ปลอดภัย ข้อมูลทั้งหมดจัดเก็บในเครื่องของคุณ 100%
6. **รองรับ PWA (Progressive Web App):**
   - เพิ่มเป็นแอพลงหน้าจอมือถือ (Add to Home Screen) มีไอคอนรูปรถ Geely E2 EV สวยงาม ใช้งานได้แบบแอปจริง

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ (ง่ายที่สุดบน Windows)
- ดับเบิ้ลคลิกไฟล์ `start.bat`
- เบราว์เซอร์จะเปิดหน้าแอพ `http://localhost:3000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / Command Prompt
```bash
npm start
```
หรือ
```bash
node server.js
```

### วิธีที่ 3: เปิดบนมือถือ (ขณะนั่งอยู่ในรถ Geely E2)
- เชื่อมต่อมือถือเข้ากับ Wi-Fi วงเดียวกับคอมพิวเตอร์
- เปิดเบราว์เซอร์ในมือถือแล้วพิมพ์ URL ตาม IP ที่คอนโซลแจ้ง (เช่น `http://192.168.1.xxx:3000`)
- สามารถกด **"Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)** เพื่อใช้งานเหมือนแอพมือถือจริงได้ทันที
